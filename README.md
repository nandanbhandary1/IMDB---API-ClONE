Designed and developed a RESTful backend application using Django and Django REST Framework, implementing
well-structured APIs that strictly follow REST principles, proper HTTP methods and standardized HTTP status codes.

Implemented secure authentication mechanisms including Token Authentication and JWT Authentication, ensuring safe
user login, session handling, and scalable stateless authentication.

Built and managed relational database models using Django ORM, defining relationships between users, streaming
platforms, watchlists, and reviews, and handled schema changes using Django migrations.
